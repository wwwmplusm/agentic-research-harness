# Source Quality

## A — primary

Official documentation, original paper, law, dataset, original report, transcript, original book/chapter.

## B — strong secondary

Textbook, academic review, expert article with citations, reputable publication.

## C — discovery/noise

SEO pages, generic blogs, unsourced summaries, weak aggregators, LLM output.

## Rules

- Search snippets are not evidence.
- C sources can help find A/B sources but should not support final claims.
- If a B source makes an important claim, chase its citation.
- If the primary source cannot be found, mark the claim as `source_gap`.
