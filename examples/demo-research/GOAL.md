# GOAL

## Why

Demonstrate how the research harness works without including private research data.

## Main question

How should an AI agent evaluate whether a web page is strong enough to support a factual claim?

## Context

This is a toy example for repository users. It should be small, readable, and safe to publish.

## Desired output

A short guide in `outputs/source-evaluation-guide.md`.

## Quality bar

The answer should distinguish primary, strong secondary, and noisy discovery sources, and should not rely on search snippets as evidence.
